# L1 dual: Python REPL as the only interface

Mirrors Prime Agent v0.10.1 (commit `8aac869`). Paths below are in the prime-agent repo.

## What is the same

| Part | Prime Agent source | Dual |
|---|---|---|
| Kernel | `prime-agent-runtime` (`rlm.repl`, protocol 3; `rlm.bash`) | The same package at the same commit, installed by `duals/scripts/setup-kernel.sh` |
| `edit` | `skills/edit` | The same package at the same commit |
| Kernel packages | `crates/pa-core/src/kernel/bootstrap/mod.rs`, `DEFAULT_RLM_EXTRA_PACKAGES` | The same 12 packages, plus `dill` for snapshots |
| Bootstrap cell | `crates/pa-core/src/kernel/bootstrap/runtime_code.rs` | Same header, `bash` binding, completion notices wired, `edit` pre-imported as a callable module |
| Tool | `crates/pa-core/src/tools/ipython.rs`: name `python_repl`, schema, description, prompt snippet, sequential execution | Same text and schema |
| Tool result text | `format_execute_text` in `ipython.rs` | Same order: stdout, stderr, result, traceback on error, unattributed background output |
| Kernel restart notice | `kernel_restart_notice` in `ipython.rs` | Same text |
| Background completion notice | `create_async_bash_completion_message` in `session_engine/messages.rs` | Same `[bash-done pid:N exit:M]` text; withdrawn when the kernel reports the result consumed |
| Waiting for background work | System prompt: without a daemon, "the run waits for live background commands ... before it exits" | At `agent_before_settle`, wait for a notice or for no live command, then continue with the queued notices |
| Prompt | `prompts/layers/core.md` (intro, Core tools), `usage.md` (REPL rules), `system_prompt.rs` (session and packages lines) | `prompt.md`, generated by `duals/scripts/port_prompts.py` |
| Only interface | Prime Agent's single tool | `setActiveTools(["python_repl"])` at session start |

## Deliberate differences

- **Not ported:** `rlm` (subagents, rung L2), `agent_message` and `agent_observe` (L3), `rlm.harness` and `refine` (L4), `mcp`, `websearch`, `attach_image`, `compact.run`, goals, heartbeats.
- **Prompt edits:** "prime-agent harness" renamed to "this harness"; the `websearch` and `attach_image` lines dropped; the daemonless line keeps only its `[bash-done]` sentence (its `rlm.spawn` and heartbeat parts describe features this rung lacks).
- **Base prompt:** Pi's own system prompt stays; the Prime text is added as a `<harness>` section. Prime Agent's environment lines (date, working directory) are covered by Pi's own.
- **Kernel state on resume:** Prime Agent snapshots and restores the namespace across resumed sessions; evaluation runs never resume, so the dual does not.
- **Streaming:** Prime Agent streams cell output to its UI while a cell runs; the dual returns it when the cell ends. The model sees the same text.

## Test

`duals/tests/test_l1_repl.py` drives Pi with a scripted fake model: only `python_repl` is declared, the prompt section is present, variables persist across calls, `bash()` and `edit()` work, and a background command's `[bash-done]` notice wakes the agent after it tried to finish.
